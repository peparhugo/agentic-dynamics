# Atlas Data Grid

An accessible React and TypeScript data grid demo designed for datasets with 100,000+ rows and 50+ columns.

## Run

```bash
npm install
npm run dev
```

## Features

- Windowed row rendering with overscan
- Drag-and-drop column ordering and pointer-based resizing
- Shift-click multi-column sorting
- Client-side filtering and simulated server-side query mode
- Single, multi, and range row selection
- Double-click or Enter inline editing
- CSV and SpreadsheetML Excel exports
- Roving-tabindex keyboard navigation and ARIA grid semantics
- Responsive layout, high-contrast focus states, and reduced-motion support
