# Experiment Results

Result JSONs and markdown reports are generated by `scripts/run.py` and other experiment scripts. They are **not tracked in version control** because the full dataset lives in the opencode session database.

## How to Access the Full Dataset

```bash
# Rebuild the inventory from all data sources
python scripts/inventory.py refresh

# List all experiments with costs and counts
python scripts/inventory.py list

# Show aggregate statistics
python scripts/inventory.py stats

# Print numbers formatted for the evidence page
python scripts/inventory.py report
```

## How to Generate Result Files

```bash
# Run a single experiment (produces JSON + markdown reports here)
python scripts/run.py --config experiments/configs/task_manager.yaml
```

All result files placed in this directory are `.gitignore`d. The authoritative record is the opencode SQLite database at `~/.local/share/opencode/opencode.db`, queried through the inventory CLI.
