# Lab Book Analyses

Run structured lab book analyses against accumulated experiment data.
Each lab book answers a specific research question.

## All 8 Labs

| # | Script | Question |
|---|--------|----------|
| 1 | `lab_claude_audit.py` | Where did Claude's $47.54 go? Per-task cost/correctness breakdown. |
| 2 | `lab_grit_matrix.py` | Correctness × escape × cost bubble chart data. |
| 3 | `lab_correctness_premium.py` | Does Claude's premium buy anything? Head-to-head on 13 task types. |
| 4 | `lab_flail_triggers.py` | What makes a model flail? Failure patterns by model/perturbation/task. |
| 5 | `lab_tool_archetypes.py` | Does tool choice (write vs patch vs bash) predict code quality? |
| 6 | `lab_task_routing.py` | Optimal model-per-task routing. Simulates 3 strategies across 30 task types. |
| 7 | `lab_basin_topology.py` | Each model's attractor basin shape: shallow/broad, deep/narrow, multi-modal, flat. |
| 8 | `lab_survival_horizon.py` | Sessions-to-bankruptcy per model. "Infinite game" framing. |

## Running a Lab

```bash
python scripts/lab_claude_audit.py        # Lab 1
python scripts/lab_grit_matrix.py         # Lab 2
python scripts/lab_correctness_premium.py # Lab 3
python scripts/lab_flail_triggers.py      # Lab 4
python scripts/lab_tool_archetypes.py     # Lab 5
python scripts/lab_task_routing.py        # Lab 6
python scripts/lab_basin_topology.py      # Lab 7
python scripts/lab_survival_horizon.py    # Lab 8
```

## Prerequisites

- `experiments/_results_summary.json` — generated by `scripts/analyze_worktrees.py`
- `experiments/_trajectory_aggregate.json` — generated by `scripts/analyze_trajectories.py`
- `experiments/inventory.json` — generated by `scripts/inventory.py refresh`

## Output

Each lab writes a `.json` file to `experiments/results/lab_<name>.json`.
Methodology docs at `experiments/lab_books/lab_<name>.md`.
