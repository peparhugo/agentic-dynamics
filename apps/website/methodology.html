The instrument

Capture the event before interpreting the outcome.

The instrument runs controlled agent work in isolated worktrees, records attempts and outcomes, executes independent tests, and derives named information without confusing a model with a measurement.

Five stages, one record.

Declare: specify workflow, factors, budget, and instrumentation. Execute: record attempts, tools, timing, tokens, and cost. Verify: run the independent test suite where available. Derive: calculate measures and coverage from the record. Compare: only compare policy arms when the design provides them.

For linked stories, five sessions commit into one another: greenfield, feature, integration, refactor, cross-cutting. That creates the inherited state the next session must confront.

[M] MEASURED capture from ledgers, tests, costs, and filesystem events.

[C] COMPUTED direct transformation of measured inputs.

[H] HEURISTIC a thresholded or algorithmic classification.

[X] EXTERNAL a linked source outside this corpus.

[P] POLICY a design, proposal, or authorization boundary.

Provenance is a method

Coverage is part of the result.

A missing test verdict, unavailable language server, untriggered escalation, or absent canonical lab output is reported as such. The instrument does not replace missing coverage with a zero, a proxy, or an older corpus value.

Known historical limitation

116 of 227 sessions in the historical precursor used heuristic correctness because no pytest suite executed. This constrains that precursor; it is not a property of the current linked-story corpus.
