ARCHITECTURE — THE SYSTEM AS BUILT

Eight planes, one direction, one measured loop.

This page depicts the repository's actual architecture, not an aspiration. It shows the eight package planes and their dependency direction, the load-bearing rule that connects measurement to policy, how an experiment specification compiles into an executable grid, and the fail-closed gate that guards every paid call. Every figure states what it depicts and carries its provenance; the elements are hand-built SVG, so the page fetches no external image.

Provenance: [P] architecture — every diagram on this page is derived from ARCHITECTURE.md §1–2 and the compiled spec design, and is cross-checkable against the modules under src/agentic_dynamics/.
HOW — THE PLANES

Eight planes, one dependency direction.

The codebase is a modular monorepo of eight bounded planes. Dependencies point one way: core is the foundation; six tier-1 planes build on it; control is the only plane that consumes the information they produce; applications are served by control. The dependency direction is enforced by a test, not a convention.

HOW — THE MEASUREMENT LOOP

To make policies, we need information.

The system is an information-acquisition machine. It instruments a workflow, derives named information from the captured events, and only then writes control rules that consume that information. A control rule whose required information is not measured cannot be written — the compiler refuses it. The loop closes when a policy runs as an arm in a grid and the campaign changes one variable to acquire the next measurement.

HOW — THE COMPILER

A spec compiles into an executable grid.

One declarative ExperimentSpec crosses factor levels into cells, validates its rules' information requirements, and compiles into a phase DAG: validate → cells → execute → measure → compare → writeup → adapt. Execution reuses the existing transport — the same jobs, attempts, and append-only ledger an ordinary workflow uses.

HOW — THE SPEND GATE

No lease, no spend.

Every paid call passes a fail-closed gate. A run first reserves a lease — a dollar lease for per-token providers, a window-percent lease for subscription providers, plus a concurrency lease — and an unknown cost is never treated as zero. The reservation is reconciled against the provider's own meter after the fact, and an expired lease raises a flag and a quarantine mark. The watchdog observes; it never steers.
