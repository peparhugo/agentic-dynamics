## 4. Verdict

**REWORK REQUIRED.** The direction stands; the artifacts do not yet carry it. Seven claimed
corrections from the prior pass are only nominal (§0): the state contract's second axis has no
measured producer (D-6), the new failure states are asserted against no specification (D-7), the
token claim is unpinnable by its named gates (D-8), F01's acceptance names a gate that cannot see
its claim (T-8/T-9), the half-migration is incomplete (T-11), F26's blocker is misidentified (T-12),
and the dynamic workflow builds on a compiler substrate that validates but does not execute
(W-9/W-10/W-11).

Highest-severity corrections: **D-6** (client-derived consequential values), **D-8** (unpinnable
token acceptance), **T-8** (browser-free gate for a browser claim), **T-10** (circular class-B),
**T-11** (incomplete half-migration), **T-12** (repo whitelist is the real blocker), and
**W-9/W-10/W-11** (executor, convergence, worked example). None is a rewrite of the direction.

**Disposition.** Each finding is accepted or amended into a1/a2 in `a4_revise`; a rejected finding
gets a one-line reason. The controller decisions remain as a1 §7 and a2 §10, plus one new decision:

- **D6 — is the class-B scorecard human-scored or machine-generated?** T-10 requires a recorded
  human pass to make class B non-vacuous; a machine-generated scorecard would make the acceptance
  circular and must be rejected explicitly.
