## Two lenses (kept in conflict until the synthesis)

**Lens 1 — Construct validity (measurement theory).** A substitution is an *operationalization*: a proxy is substituted when it fails **discriminant validity** against the authority construct — it moves for its own reasons, not (only) because the criterion moved. The arc's canonical instance: a message count moving with the session, not with capacity. This lens demands a criterion measure, and for "substitution incidence" the criterion lives in production decisions, not in the proposal. Consequence: a detector validated on the corpus that produced the law is **circular**.

**Lens 2 — Static-analysis engineering (lint design).** A detector must be decidable from the artifact alone. The criterion measure is unavailable at lint time, so the rule must approximate with a *narrow* trigger and an explicit **precision budget**, or it is unusable. Consequence: "mentions the authority" becomes itself a proxy — and the honest move is to *declare* that proxy and bound it, not deny it.

**Conflict (visible):** Lens 1 says the textual lint is itself a substitution (proxy: authority-mentions; criterion: correctness) and should be rejected. Lens 2 says no detector can do better from the artifact, so the only validator is a differential oracle that falsifies the lint. I do not blend these; the artifact below is Tier 1 under Lens 2, *bounded* by a Tier-2 oracle that answers Lens 1.

## The artifact

### (a) Pattern — what a substitution looks like in a proposal

```
SUBSTITUTION := CLAIM_ACT(proxy) ∧ GATES(action) ∧ ¬ANCHOR(authority)

CLAIM_ACT  ∈ {is, means, passes, green, accepted, verified, done, safe, within,
              permits, allows, blocks, closes, submits, merges, promotes}
GATES      = the claim licenses or forbids an action (allow/deny/submit/merge/close)
proxy      = a number/state adjacent to the criterion (cheaper, correlated, nearby)
ANCHOR     = a token that binds the claim to the authority's OWN output or to a diff:
             {opencode, runtime, resolve_capacity, diff, compare, ported from, same
              calculation, matches the, oracle, measured against, reproduced, exact
              expression, provenance}
```

Four illicit **bridge forms** the claim-act takes (these are the fixtures' shapes):

| Bridge | Form | Arc instance (fixture id) |
|---|---|---|
| Identity | "X **is** Y" | `968_000` is the gate's correctness (T12) |
| Gate | "if X, allow/close" | 200,000 gates the session (T1); 80 turns closes it (T2) |
| Progress | "X happened, **so** Y is done" | `fleet:jobs <- launching` ⇒ run started (T8); CI green ⇒ correct (T7) |
| Uniformity | "X is policy, not measured" | 80% / turns as "configurable policy" (T2) |

### (b) Checklist / check

Six questions per gated claim (usable by hand or by the tool):
1. **Gate?** Does the claim license/forbid an action? If no → not in scope.
2. **Quantity?** Does it rest on a number or state? If no → not a substitution.
3. **Criterion?** Name the authority output the claim is *really* about (one sentence).
4. **Identity?** Is the cited quantity that output, or a function of it? If yes → clean.
5. **Diff?** Is there an authority-anchor — a comparison, a ported expression, a CLI resolution, a test that fails on divergence? If yes → `REPAIRED` (record it; do not flag).
6. **Direction?** If it can say OK when the authority says no → `false-permit` (safety); if it can say no when the authority says OK → `false-refuse` (velocity). The operator's remedy differs, so the flag must carry it.

**Executable spec (paths + commands; presented, not executed — CONTEMPLATION):**

```python
# scripts/proposal_substitution_lint.py  — Tier 1: prose, precision-first.
# Rule: fire only on GATED metric claims with no ANCHOR. Reason: recall is recoverable
# by review; a corpus-level false-positive storm destroys adoption (Lens 2).
GATE_LEMMAS = ("passes","accepted","green","verified","done","safe","within","permits",
               "allows","blocks","closes","submits","merges","promotes","is correct","proves")
METRICS = ("200,000","80 turns","turn budget","context tokens","summary.tokens","reasoning",
           "phases","cache read","checks","launching","PID","effective_limit","968,000")
ANCHORS = ("opencode","runtime","resolve_capacity","diff","compar","ported from",
           "same calculation","matches the","oracle","measured against","reproduced",
           "exact expression","fails if","provenance")
AUTHORITY_REGISTRY = {  # delegated gates are legitimate authority — data, reviewable.
  "admission lease":        "control.lease_registry (operator-armed)",
  "broker re-validation":   "launch_broker.run_fleet_command (host strict gate)",
  "required CI checks":     "branch protection (operator-owned)",
  "approval checkpoint":    "approve_workflow.py (operator signature)"}

def classify(claim: str) -> dict | None:
    low = claim.lower()
    gate = next((g for g in GATE_LEMMAS if g in low), None)
    metric = next((m for m in METRICS if m in low), None)
    if not (gate and metric):
        return None                                  # out of scope — no flag
    if any(a in low for a in ANCHORS) or any(k in low for k in AUTHORITY_REGISTRY):
        return {"verdict": "REPAIRED", "metric": metric}      # a diff is present
    direction = ("false-permit" if gate in
                 ("accepted","green","done","verified","safe","launching") else "false-refuse")
    return {"verdict": "SUBSTITUTION", "metric": metric, "direction": direction}
```

### (d) False positives it will produce (predicted, not measured)

1. **Metalinguistic mention (dominant).** Wave-1 is *about* substitution; `T`-pattern sentences appear as diagnoses (c17's law sentence), and the lint fires. Mitigation: whitelist sentences whose object is itself a quoted claim.
2. **Repaired proxy with a diff** (my own FP list, T8/T12) — lexically near-miss. Mitigation: anchor window ±1 sentence; treat as `REPAIRED`, not clean, so recall on *unrepaired* text is preserved.
3. **Delegated authority** (admission lease, broker re-validation) — flagged unless the registry resolves it. The registry is the mitigation *and* the attack surface (who reviews the registry?).
4. **Negation/hedge scope** — "the gate does **not** treat the constant as capacity" and honest `UNJUDGED` wording. Mitigation: negation window; flag becomes `MENTION`.
5. **Table/header extraction loss** — prose splitters miss claims in tables (also a false-negative class).
6. **Quoted history** — the close record quotes the 200K policy as history; flagged as live. Mitigation: quote/attribution detection.
**False negatives (kept visible):** constants in code (Tier 1 blind — hence Tier 2), substitutions with no claim verb, and the corpus's own circularity (below).
