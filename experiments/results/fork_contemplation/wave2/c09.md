## 1. Reconciliation decision — a typed wave grammar

**Design decision — why a grammar rather than a narrative.** The corpus's own failures were category errors: prose (retrospectives, doctrine) was read as if it could change outcomes, and green mechanisms (CI, admission, `fleet:jobs[… ] <- launching`) were read as if they were product. `7948b8ace287e881` is the measured disproof that instruction-prose moves accepted outcomes. A grammar makes the category error mechanically detectable.

```
# Types (every wave output MUST be exactly one; unclassifiable output is REJECTED)
SETPOINT   # authority/value only a human may originate:
           #   operator directives, acceptance criteria, scope, spend authority, ownership
           # admissible iff: prose AND referenced by >=1 MECHANISM as input
           #   (a SETPOINT with no consuming mechanism is INERT prose — rejected)
MECHANISM  # a claim about system behavior a machine can decide:
           #   MUST be executable, MUST have a pass/fail exit, MUST name an owner,
           #   MUST cite its reference standard (the authority it is a diff against)
NARRATIVE  # everything else (contemplation, retrospective, close record)
           # carries NO authority; admissible only as a SEED for a MECHANISM

# Precedence
SETPOINT > MECHANISM > NARRATIVE          # a later wave may not override an earlier SETPOINT
MECHANISM supersedes MECHANISM iff it passes a DIFFERENTIAL against the same authority
```

**The boundary decision (which side wins, under what boundary).** Mechanism wins for every *checkable* predicate, including "did we honour the prose". Prose wins only inside the setpoint/authority wall: what is wanted, who may act, what counts as acceptance. **At the edge where no mechanism exists, prose/human judgement is retained — but only tagged `INTERLOCK (UNCONVERTED)`, with an owner and a conversion obligation.** That tag is the reconciliation of L1 and L2: L1 is satisfied because the interlock is explicitly provisional and ranked below any working detector; L2 is satisfied because removing it before the detector exists is forbidden.

**How this resolves the sharpest intra-corpus conflict** — c11 (attack on measurement/fork/milestone as the unit) vs c17 (the fan-out as the unit that produces the oracle): the fan-out is legitimate *only if it emits a MECHANISM or a SETPOINT*. A second narrative wave (wave 2 as more prose) is subordinate to c11 by the corpus's own standard, regardless of how good its prose is. Reconcile wave 1 and wave 2 by extraction, not by averaging: mine wave 1 for seeds, check each wave-2 claim for a mechanism; where wave 2 has only prose, wave 2 has produced nothing.

