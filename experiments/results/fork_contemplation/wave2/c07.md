**Entry claim (one sentence, operationally falsifiable).**
A contemplation wave that ships no independently checkable artifact — an executable differential oracle, a pre-registration with a numeric decision boundary, or a deterministic harness — is a **net cost at any positive spend**: its realized cost per promoted accepted outcome is strictly worse than the single-harness baseline.

*(I adopt the prompt's claim and make it measurable; §L1 below records where I think it is most likely wrong, and I do not hide that.)*

---

## Two lenses (kept in conflict, not blended)

**L1 — Measurement / experimental design.**
The only artifact that pays is a **diff against an authority** — the thing whose behavior we actually care about (the installed runtime, the control database, the render gate). A document is a claim; a diff is a test. Prediction: mandatory artifacts raise accepted outcomes **iff** `authority_diff` is required; a costly-but-contentless artifact changes nothing.

**L2 — Mechanism design / information economics.**
The artifact pays because it is a **costly signal** that screens cheap talk out of the wave. Content is secondary to commitment cost. Prediction: *any* artifact with real cost — even a fixed harness run — contracts wave count and raises accepted outcomes per dollar.

**Visible conflict.** L1 says *content* is load-bearing; L2 says *cost* is. The policy below does not settle this by assertion: it carries an `artifact_mode` arm (`authority_diff` | `contentless_costly` | `none`) so the two predictions separate on the next windows. If the arms are statistically indistinguishable, L2 won and the required set is over-specified (still enforceable, just not for the stated reason).

## What this adds beyond c17

Wave-1 sibling **c17** proposed the detector: *Q-B, a standing differential interrogator* (diff `resolve_capacity()` against `opencode models --provider --verbose` on every check) and *Q-A, a pre-registered dose–response quality boundary*. What I add is the **governance wrapper**: c17 asks whether the machine *can* detect the discrepancy; this policy makes an authority-diff artifact the wave's **admission condition**, attaches **maxima**, and makes the **wave format itself conditional** (a single harness when the work is mechanical or diminishing). c17 is an oracle proposal; this is the control law that makes the oracle mandatory and funds it only from previous accepted outcomes.

## The policy (four required parts)

### 1. Required artifacts per wave (closed set)

A wave **conforms** only if it ships ≥1 artifact of these kinds. Prose, "insight", and questions without a boundary are classified as `question` and do **not** satisfy the wave.

```yaml
# experiments/definitions/configs/contemplation_policy.yaml
# WHY a closed set: an open "artifact" definition is enforced by judgment, and judgment is the
# cost we are trying to remove. Three kinds are checkable by field-presence + command exit.
schema: contemplation-policy/v1
artifact_kinds:
  oracle:
    # A. executable diff against an authority. WHY these four fields: path/command make it
    # runnable, authority names what is treated as truth, expected_diff makes success falsifiable
    # (a command that always exits 0 is not an oracle).
    required_fields: [path, command, authority, expected_diff]
  preregistration:
    # B. an experiment spec. WHY numeric boundary: "explore X" is a question, not an experiment;
    # a decision boundary converts it into a bet the detector can score.
    required_fields: [path, hypothesis, decision_boundary, data_source, falsifier, due_window]
  harness:
    # C. deterministic recompute. WHY seed_inputs: same inputs must reproduce the same numbers,
    # else it is an oracle with an unstable authority.
    required_fields: [path, command, seed_inputs]
```

### 2. Maxima (per N accepted outcomes **or** per budget)

Both forms are enforced; **the tighter one binds**. The budget form is always computable; the outcome form is a ratio that goes to infinity at zero accepted outcomes — that infinity is the brake.

```yaml
window: 5                    # N, rolling waves
maxima:
  spend_max_usd: 0.50        # BUDGET FORM. Calibrated: wave 1 measured $0.14184 (b8c06bc1…),
                             # so the cap allows ~3 waves before the wallet is empty.
  min_accepted_outcomes: 1   # OUTCOME FORM. At least one promoted outcome per window.
  max_fanouts_per_accepted_outcome: 5   # = window / min_accepted_outcomes; the ratio ceiling
  brake_when_accepted_zero: true        # accepted == 0  =>  ratio = inf  =>  freeze fan-out
  harness_baseline_usd: 0.024           # 5x the measured fork unit $0.004735 (c50f37cf…):
                                        # the cost a SINGLE harness must beat to justify itself
```

### 3. Promotion trigger (question → experiment)

A question becomes an experiment when this predicate is true. Six cheap booleans; two are mandatory; the rest is a threshold.

```yaml
promotion:
  min_score: 5               # of 6; WHY 5 not 6: authority_diff is waived for a
                             # pre-registration (a dose–response has no single authority diff).
  mandatory: [falsifier, signal]
  checks:
    - {name: falsifier,        field: falsifier,           kind: nonempty}
    - {name: signal,           field: signal,              kind: nonempty}  # data source + quantity
    - {name: boundary,         field: decision_boundary,   kind: numeric}
    - {name: affordable,       field: est_cost_usd,        kind: lte, value: 0.05}  # <= 1/3 wallet
    - {name: authority_diff,   field: authority_diff,      kind: is_true}          # waivable by
      # preregistration: a boundary + data source IS the diff for a dose-response.
    - {name: owner_and_due,    field: owner,               kind: nonempty}         # owner+due_wave
```

Promoted questions become a spec at `experiments/specs/<id>/` (or a workflow run) with an owner and a due wave. **Unpromoted questions are dropped, not stored** — storing them re-creates the cost the policy removes.

### 4. Replacement trigger (wave → single harness)

Replace the multi-agent fan-out with one deterministic harness when any disjunct fires:

```yaml
replacement:
  mechanical_fraction: 0.80   # >=80% of the wave's questions are fixed probes => no model judgment
  zero_accepted_waves: 2      # two consecutive windows at zero accepted outcomes ...
  duplication: 0.60           # ... and >=60% question overlap (Jaccard) => diminishing returns
  harness_recall: 0.80        # a replay harness reproduces >=80% of promoted questions ...
  harness_cost_fraction: 0.20 # ... at <=20% of the median wave cost
```

When fired, run the single harness instead: `python3 scripts/contemplation_harness.py --from-wave <id> --probes <file>`. The harness is `kind: harness` by construction, so the wave still conforms to §1.

**Ablation arm (why the policy can be wrong):**

```yaml
ablation:
  # Rotates windows across arms so "why do artifacts work?" is an experiment, not an assumption.
  artifact_mode: authority_diff   # authority_diff | contentless_costly | none
```

**Detector — `scripts/check_contemplation_policy.py`** *(analysis-only: presented, not run)*

```python
#!/usr/bin/env python3
"""check_contemplation_policy.py — enforce contemplation-policy/v1.

WHY THIS EXISTS. The entry claim is a governance claim; if enforcing it costs reading prose,
the enforcement is itself the disease. This detector reduces the policy to six booleans per
answer and four window predicates, so the marginal cost of enforcement is one CI command.

WHAT IT READS.
  * policy          experiments/definitions/configs/contemplation_policy.yaml
  * current wave    experiments/results/fork_contemplation/<wave>/manifest.json
  * wave journal    experiments/results/control/contemplation_waves.jsonl (append-only)

EXIT CODES (disjoint, 0-on-success, mirroring scripts/session_budget.py so `&&` chains work):
  0 OK            conforms AND within maxima
  2 NONCONFORMING no required artifact — the wave may log questions but not merge prose
  3 BRAKE         window overspent OR produced zero accepted outcomes; freeze fan-out,
                  the next wave must be the single harness
  4 REPLACE       replacement trigger fired; run scripts/contemplation_harness.py instead
  5 UNJUDGED      policy/manifest unreadable — never silently OK

DESIGN DECISION: pure stdlib + PyYAML, no model calls, <1s, so it rides the fast-path gate.
"""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

import yaml  # already a project dependency (pyproject: pyyaml>=6.0)

# ----------------------------------------------------------------------------- artifact gate
# WHY a closed kind set: an open definition is enforced by judgment, which is the cost.
ARTIFACT_KINDS = ("oracle", "preregistration", "harness")


def artifact_ok(artifact: dict, kinds: dict) -> bool:
    """True iff the artifact's kind is in the closed set and every required field is present,
    non-empty. WHY presence-only: field *quality* is what the authority diff tests later; an
    enforcement gate that judges quality reimports the judgment cost the policy exists to shed."""
    kind = artifact.get("kind")
    if kind not in ARTIFACT_KINDS or kind not in kinds:
        return False
    required = kinds[kind].get("required_fields", [])
    return all(artifact.get(f) not in (None, "", [], {}) for f in required)


def wave_conforms(manifest: dict, policy: dict) -> bool:
    """A wave conforms iff at least one answer ships a complete artifact of a required kind."""
    kinds = policy["artifact_kinds"]
    return any(
        any(artifact_ok(a, kinds) for a in answer.get("artifacts", []))
        for answer in manifest.get("answers", [])
    )


# --------------------------------------------------------------------------- promotion trigger
def score_question(q: dict, policy: dict) -> tuple[int, list[str]]:
    """Score a question's promotion metadata, returning (score, reasons-it-failed).

    WHY explicit per-check code rather than a generic expression evaluator: a generic evaluator
    is another configuration system to keep in sync with the runtime; six literal checks cannot
    drift. Each check is a design decision:
      falsifier      — a claim that can be proven wrong is the minimum unit of an experiment.
      signal         — a named data source + quantity; without it the boundary is unfalsifiable.
      boundary       — numeric; "improve X" is not a bet.
      affordable     — est_cost <= 1/3 wallet; an experiment that cannot fit in the budget
                       cannot be funded by an accepted-outcome-gated wave.
      authority_diff — a diff against an authority, OR a pre-registration (a dose-response IS
                       its own authority diff: the boundary is the authority).
      owner_and_due  — an unowned experiment is a question.
    """
    checks: list[bool] = []
    failed: list[str] = []
    mandatory = set(policy["promotion"]["mandatory"])

    def check(name: str, ok: bool) -> None:
        checks.append(ok)
        if not ok:
            failed.append(name)

    check("falsifier", bool(str(q.get("falsifier") or "").strip()))
    check("signal", bool(str(q.get("signal") or "").strip()))
    check("boundary", isinstance(q.get("decision_boundary"), (int, float)))
    check("affordable", float(q.get("est_cost_usd", 1e9)) <= policy["promotion"]["checks"]["affordable"]["value"])
    # authority_diff is waivable only by a preregistration-shaped question.
    waivable = q.get("kind") == "preregistration"
    check("authority_diff", bool(q.get("authority_diff")) or waivable)
    check("owner_and_due", bool(str(q.get("owner") or "").strip()) and bool(str(q.get("due_wave") or "").strip()))

    missing_mandatory = [m for m in mandatory if m in failed]
    score = sum(checks)
    if missing_mandatory:
        return score, failed
    return score, failed


def promotable(q: dict, policy: dict) -> bool:
    score, failed = score_question(q, policy)
    return score >= policy["promotion"]["min_score"] and not (set(policy["promotion"]["mandatory"]) & set(failed))


# ----------------------------------------------------------------------- window maxima + brake
def window_state(journal: list[dict], policy: dict) -> dict:
    """Fold the rolling window. WHY a window and not a lifetime: the entry claim is about the
    *current* format's marginal value; a lifetime average can hide a dead arm for many waves."""
    n = int(policy["window"])
    window = journal[-n:]
    spend = round(sum(float(w.get("spend_usd", 0.0)) for w in window), 6)
    accepted = sum(int(w.get("accepted_outcomes", 0)) for w in window)
    maxima = policy["maxima"]
    over_budget = spend > float(maxima["spend_max_usd"])
    zero_accepted = accepted < int(maxima["min_accepted_outcomes"])
    return {
        "spend_usd": spend,
        "accepted_outcomes": accepted,
        "over_budget": over_budget,
        "zero_accepted": zero_accepted,
        "ratio": None if accepted == 0 else round(len(window) / accepted, 3),
        "max_fanouts_per_accepted_outcome": maxima["max_fanouts_per_accepted_outcome"],
    }


# --------------------------------------------------------------------------- replacement trigger
def replacement_fires(manifest: dict, journal: list[dict], policy: dict) -> tuple[bool, str]:
    """The wave→harness replacement trigger. WHY disjunctions, not a score: any one of these is
    sufficient to prove the fan-out is not earning its cost, and waiting for all of them spends
    more than it saves. Each disjunct is a falsifiable predicate over typed fields."""
    r = policy["replacement"]
    answers = manifest.get("answers", [])
    questions = [a.get("promotion", {}) for a in answers]
    if questions:
        mech = sum(1 for q in questions if q.get("mechanical")) / len(questions)
        if mech >= float(r["mechanical_fraction"]):
            return True, f"mechanical_fraction={mech:.2f}>={r['mechanical_fraction']}"
    zero_windows = 0
    for w in reversed(journal):
        if int(w.get("accepted_outcomes", 0)) == 0:
            zero_windows += 1
        else:
            break
    if zero_windows >= int(r["zero_accepted_waves"]) and float(manifest.get("duplication", 0.0)) >= float(r["duplication"]):
        return True, f"{zero_windows} zero-accepted windows and duplication={manifest.get('duplication')}"
    if manifest.get("harness_recall") is not None:
        # Offline replay numbers, when a harness exists. WHY require BOTH recall and cost:
        # a cheap harness that loses questions is not a replacement, it is a smaller wave.
        if float(manifest["harness_recall"]) >= float(r["harness_recall"]) and \
           float(manifest.get("harness_cost_fraction", 1.0)) <= float(r["harness_cost_fraction"]):
            return True, "harness dominates on replay (recall and cost)"
    return False, ""


# ------------------------------------------------------------------------------------ CLI main
def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(description="Enforce contemplation-policy/v1 (see module docstring).")
    p.add_argument("--policy", default="experiments/definitions/configs/contemplation_policy.yaml")
    p.add_argument("--wave", required=True, help="wave id, e.g. fork_contemplation/wave2")
    p.add_argument("--journal", default="experiments/results/control/contemplation_waves.jsonl")
    p.add_argument("--json", action="store_true")
    args = p.parse_args(argv)
    try:
        policy = yaml.safe_load(Path(args.policy).read_text())
        manifest = json.loads(Path(f"experiments/results/{args.wave}/manifest.json").read_text())
        journal = [json.loads(l) for l in Path(args.journal).read_text().splitlines() if l.strip()]
    except (OSError, ValueError, KeyError) as exc:
        print(f"UNJUDGED: {exc}")           # never a silent OK
        return 5

    conform = wave_conforms(manifest, policy)
    state = window_state(journal, policy)
    replace, why = replacement_fires(manifest, journal, policy)
    promoted = [a["id"] for a in manifest.get("answers", []) if promotable(a.get("promotion", {}), policy)]

    report = {"wave": args.wave, "conforms": conform, "window": state,
              "promote": promoted, "replace": replace, "replace_reason": why}
    print(json.dumps(report) if args.json else json.dumps(report, indent=2))
    if not conform:
        return 2
    if state["over_budget"] or state["zero_accepted"]:
        return 3                              # BRAKE: no new fan-out until an outcome lands
    if replace:
        return 4                              # REPLACE: run the single harness
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

"""Counterexample tests for contemplation-policy/v1. Each test IS a falsifier of one clause."""
from scripts.check_contemplation_policy import promotable, replacement_fires, wave_conforms, window_state

P = {"artifact_kinds": {"oracle": {"required_fields": ["path", "command", "authority", "expected_diff"]},
                        "preregistration": {"required_fields": ["path", "hypothesis", "decision_boundary",
                                                                "data_source", "falsifier", "due_window"]},
                        "harness": {"required_fields": ["path", "command", "seed_inputs"]}},
     "window": 5, "maxima": {"spend_max_usd": 0.5, "min_accepted_outcomes": 1,
                             "max_fanouts_per_accepted_outcome": 5, "brake_when_accepted_zero": True},
     "promotion": {"min_score": 5, "mandatory": ["falsifier", "signal"],
                   "checks": {"affordable": {"value": 0.05}}},
     "replacement": {"mechanical_fraction": 0.8, "zero_accepted_waves": 2,
                     "duplication": 0.6, "harness_recall": 0.8, "harness_cost_fraction": 0.2}}


def test_prose_only_wave_is_nonconforming():
    # The entry claim's minimum: prose alone must not satisfy the wave.
    assert wave_conforms({"answers": [{"id": "c1", "artifacts": []}]}, P) is False


def test_an_incomplete_artifact_does_not_count():
    # "I wrote a test" without a command is a claim; the gate requires runnable fields.
    bad = {"answers": [{"id": "c1", "artifacts": [{"kind": "oracle", "path": "x"}]}]}
    assert wave_conforms(bad, P) is False


def test_authority_diff_is_waived_only_for_a_preregistration():
    q = {"falsifier": "f", "signal": "s", "decision_boundary": 0.8, "est_cost_usd": 0.01,
         "authority_diff": False, "owner": "aio", "due_wave": "wave3", "kind": "question"}
    assert promotable(q, P) is False
    assert promotable({**q, "kind": "preregistration"}, P) is True


def test_zero_accepted_window_brakes_even_when_cheap():
    # Cost minimal + zero outcome is the exact case the entry claim calls net-negative.
    state = window_state([{"spend_usd": 0.01, "accepted_outcomes": 0}] * 5, P)
    assert state["zero_accepted"] and state["ratio"] is None


def test_mechanical_wave_is_replaced_by_the_harness():
    manifest = {"answers": [{"promotion": {"mechanical": True}}] * 4}
    replace, _ = replacement_fires(manifest, [], P)
    assert replace is True
