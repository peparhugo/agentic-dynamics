## 1. Most important findings

## 2. Most important risks / mistakes to avoid

1. **Trusting a synthesis over its inputs.** The syntheses "are the least trustworthy documents in this package; the individual answers are the primary material" (`evidence/contemplation_waves_1_2_review.md:31-33`). Avoid quoting cross-sibling conclusions as findings.
2. **Reading acceptance as effect.** Empty queue ≠ dispatched restart; queued submit ≠ running run; green gates ≠ correct behavior (`evidence/aio_arc_findings_and_results.md:174-177,223`). Require a durable terminal record for every effectful control act (the `wave2/c04` entry claim, `evidence/contemplation_waves_1_2_review.md:94`).
3. **Hardening on inconclusive data.** The context-dose rule `UCB95(−τ_g) > δ` "needs technical review before implementation" — it says substantial harm remains *possible*, not established, and could recreate the unwanted cutoff (`evidence/aio_arc_findings_and_results.md:206-209`; `evidence/contemplation_waves_1_2_review.md:114-117`).
4. **Building generalized infrastructure.** "Do not build a generalized prose compiler or another governance framework" (`evidence/aio_arc_findings_and_results.md:204-205`); keep the next step inside existing machinery (`:140-143`).
5. **Assuming fork transport.** Frozen real-session Docker forks remain **unproven**; forks must be transported (explicit parent identity, per-cell snapshots, refuse on missing/mismatched bytes) — never a silent fresh session (`evidence/aio_arc_findings_and_results.md:218-220,229`).
6. **Emitting without retrieval verification.** An emission event alone is insufficient; the old extraction (canonical line + last line, 200 chars) discarded substance, and two report bodies could extract identically (`evidence/contemplation_waves_1_2_review.md:136-143`). Keep the mid-report retrieval + evidence-link test.
7. **Reading an empty scoped result as "no knowledge".** A scoped pipeline query can return 0 for generic queries because the pre-filter admits only exact-scope records (`evidence/retrieval_audit.md:22-24,49-50`); the CLI reader (`kb_read.py`) closes access but not the scope rule (`:57-61`).
8. **Acting on a stale measurement.** The retrieval verdict is stale once emission switches change (`evidence/retrieval_audit.md:54-55`), and the historical stale-next-action binding ("activate, then submit" after both happened) is a live instance of instructions outliving reality (`evidence/aio_arc_findings_and_results.md:179-180`).

## FINDING

One failure recurs across the evidence: measuring a cheap proxy instead of the authority's own output. Wave syntheses read 4,000-char excerpts (wave 1) or no siblings (wave 2); `final_response` was omitted from the ledger, hiding delivery; an empty queue passed for a completed restart; 302,080 cache-reads is a count misread as a hit rate; retrieval returns spec churn because analysis was never emitted. The 2026-09-20 correction is the right model: reject claims whose inputs were bounded, keep disagreements, demand executable oracles. Best next move: re-run the standing retrieval audit now that all 20 `emit_self` opt-outs flipped; its trigger fired, and it is the cheapest test of the emission repair. Do not launch wave 3 or the Q-B harness first.
