# About This Site

Welcome to my static site generator example! This site demonstrates the powerful template and layout system.

## Features

- **Handlebars Templates**: Use familiar template syntax
- **Layout System**: Wrap content with reusable layouts
- **Partials**: Share common components like headers and footers
- **Frontmatter**: Specify template and layout per page
- **Backward Compatible**: Works without templates too

## Technology

This site is built with a TypeScript-based static site generator that supports:
- Markdown content with YAML frontmatter
- Handlebars template engine
- Custom layout and template system
- Partial includes for DRY templates
