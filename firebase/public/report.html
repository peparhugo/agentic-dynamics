Executive Summary

We discovered a 69× cost gap between models that produce identical constraint-complete Python code. The gap is structural — not situational. DeepSeek v4 Pro uses GRPO-based latent reasoning (Silent Inference); Claude Fable 5 uses SFT imitation chain-of-thought (billed as output tokens). The framework measures the cost. You decide which model fits your context.

Your AI bill is a black box. This framework opens it.

The Five Rules

Rule 1 — Grit (Ground-Truth Integrity)

Default to the cheapest model that passes your test suite. Models with high Grit maintain correctness under degraded, contradictory, or incomplete instructions. Defaulting to Grit-tested models preserves budget runway for tasks that actually need explicit reasoning — database migrations, core architecture, security audits. Two-way door.

Rule 2 — The Explanation Tax Rule

Narration has a measurable cost (24–120%). Whether it's worth paying depends on your verification architecture. If automated tests validate output, route to silent models. If you need auditable reasoning, the tax is insurance.

Rule 3 — The Snowball Rule

Model cumulative cost before architectural commitments. Context inflation compounds quadratically: C(N,v) = C₀ × EPM(N) × [N + β·v·N(N−1)/2]. The β·v·N² term dominates long-run cost. One-way door.

Rule 4 — The EPM Horizon Rule

Energy costs are the inflation rate of AI compute. Local energy markets determine long-term prices. Find the year your geographic energy costs flip your model selection. EPM(t) = 1.00 + r(t−2024). Hedge before that point.

Rule 5 — The Cost-Per-Pass Rule

Price the outcome, not the prompt. A model at half the cost but half the pass rate costs the same per outcome — with double the latency and retry overhead. CostPerOutcome(K,v) = C(K/P, v) / K.

Rule 6 — Batch Discount

Defer non-urgent work to 72-hour batch windows. Batch-eligible tasks at 50% cost open budget headroom. Two-way door.

Rule 7 — Budget Ceiling

Enforce per-model, per-workstream spend caps. Prevent reasoning models on trivial tasks. Track WOC ratio across teams.

Rule 8 — Cascade Rule

Route 78.6% of tasks to the cheapest tier that passes validation. Escalate only when quality gates fail. Two-way door.

Rule 9 — SLA Buffer

Reserve 15% of budget runway for SLA-critical escalations. The buffer absorbs reasoning model spikes without breaking the budget.

Rule 10 — First-Pass Rule

Track WOC = 1/(1+r). WOC ratio below 0.70 is critical — model replacement is cheaper than retry. At or above 0.90 = healthy.

Decision Framework

Two-Way Doors (C₀ changes): Switch models per task type, toggle silent mode, adjust caching. Reversible. Preserves runway. Experiment freely.

One-Way Doors (β, v, EPM changes): Architecture selection, multi-year contracts, proprietary frameworks. These compound through N². Model cumulative cost over 36 months before committing.

Methodology

The instrument runs 10 perturbation operators (4 manifold, 6 semantic) across 34 YAML configs covering Python and TypeScript. Six recovery detection signals classify model behavior. Four strategy archetypes (Conservative, Exploratory, Wasteful, Efficient) characterize response patterns. Every session recorded in the opencode database.

Research Roadmap (v0.4+)

Pillar 1: Multi-language AST expansion — TypeScript (in progress: 21 runs), Go, Rust, Java. Pillar 2: Task archetypes — bug-fixing, refactoring, security. Pillar 3: Model diversity — Gemini, Llama, Mistral. Pillar 4: Structural perturbations — dependency injection, AST corruption. Pillar 5: Maintenance tax — human-in-the-loop studies.

Current Scope & Limitations

Validated on Python/Flask REST APIs, CRUD apps, and real-time collaboration frontends. TypeScript/Node.js baselines in progress (3 architectures, 21 cross-model runs). Not yet validated on Go, Rust, or non-code tasks. EPM uses IEA baseline (1.6%/yr). The framework measures inference cost only — it does not model human maintenance or debugging time. v0.4.
