Key Findings

From 74 experiment sessions across 4 experiment types.

STRATEGIC FAILURE
Claude Fable 5 produced 0 tool calls on 40% of perturbed runs. It defaulted to explaining architecture rather than building it. DeepSeek built working code on 92% of all runs regardless of perturbation. The RL-vs-imitation policy difference manifests as agentic behavior: one model abandons the task, the other pushes through.
COST COMPOUNDING
The cost factor starts at ~20x on tiny tasks (5 files, URL shortener) and compounds to 59x on iterative development (4-phase build). Modeled at a 500-file production codebase: 2,600x. Claude's cache-write tax compounds because every new session re-reads the growing codebase. DeepSeek's cost stays flat — it only processes the tokens it needs.
PERTURBATION RESPONSE
When constraints are removed, DeepSeek burns 87% more tokens re-deriving them (constraint awareness). Claude simplifies — fewer tools, shallower depth. When alien vocabulary is injected, DeepSeek explores with higher depth and the only retry observed. Claude stops building entirely. The models have fundamentally different strategies for handling unexpected inputs.

Methodology

How the instrument works.

Agentic Execution

Each experiment spawns an isolated opencode run session with git-initialized worktree. The model writes files, runs tests, iterates on failures. No raw API calls — real agentic behavior with tool-call tracing.

10 Perturbation Operators

Calibrated operators at strengths 0.0–1.0. Classified as manifold (alien vocab, framing shifts, causality inversion — push embeddings off-manifold) or semantic (false premises, missing constraints, contradictions — test reasoning quality within the learned manifold).

Output-Based Measurement

Measures what was built, not what was said. Architecture divergence (different tech choices?), structure divergence (different code organization?), correctness, constraint satisfaction. Escape = did the model produce a structurally different solution?

Cost Accounting

Uses opencode's cumulative session cost — not derived token math. Captures cache writes, reasoning tokens, and total session cost. Tracks $/Mtok, $/correct build, and energy estimates per session.
