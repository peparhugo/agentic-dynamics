Formal Definition — The Silent Inference Principle

A model exhibits Silent Inference when it correctly implements all required constraints in its output artifact without generating explicit narration, explanation, or reasoning trace about those constraints. Three measurable dimensions: (1) Detection — does the model know the constraint exists? (latent, measured via code scanning); (2) Implementation — does the final artifact handle the constraint? (measured via test pass rate); (3) Narration — does the model say it handled the constraint? (measured via reasoning text analysis). Silent Inference: Implementation=True, Narration=False. The Explanation Tax is the cost delta from Narration=True — paid by explicit inference models, evaded by silent inference models.

Part 4 — The Model

The AI FinOps Cost Equation.

All terms measured from experiment data or sourced from published energy projections. This is the unified model — from a single session to a 100-engineer enterprise, from 2024 to 2050.

C₀           = baseline session cost at 2024 energy prices (measured)
EPM(t)       = Energy Price Multiplier at time t
β            = tokens per line of code ≈ 0.001 (context inflation)
v            = velocity (lines per session)
N            = number of sessions
P            = test pass rate (correctness)
K            = desired successful outcomes
A            = architectural multiplier (active params ratio)
ϵ            = explanation tax (natural/forced cost ratio − 1)

Per-session cost:
  c(t) = C₀ × EPM(t) × (1 + β·v·t)

Cumulative cost after N sessions:
  C(N,v) = C₀ × EPM(N) × [N + β·v·N(N−1)/2]

Cost per successful outcome:
  CostPerOutcome(K,v) = C(K/P, v) / K

Team-scale monthly cost:
  C_month = E × C₀ × EPM(N_month) × [N_month + β·v·N_month(N_month−1)/2]
  where N_month = sessions/day × working days/month per engineer

Decomposing the total cost gap between models:
  Gap = (A × Verbosity × (1+ϵ)) × EPM(N)
  A = Claude active params / DS active params ≈ 13.5×
  Verbosity = Claude code tokens / DS code tokens ≈ 3.5×
  ϵ = DS 24.4%, Claude 52.5%, GPT-5.6 50.1%, GPT-5-mini 119.6%
CTO How to use this equation: You don't need to solve it yourself. Plug in your team size (E), sessions per day, desired outcomes (K), and time horizon. The equation tells you: (1) which model is cheapest per outcome today, (2) when the cumulative cost of a cheaper/lower-pass-rate model overtakes a more expensive one, and (3) how much extra you'll pay in 2030 when energy prices rise 1.2×. This is the only framework that connects per-session costs to long-term energy risk.

Part 6 — Data & Research Context

The evidence behind the instrument.

Worktree Inventory — 139 Code Artifacts

Full pytest execution on all on-disk worktrees. Claude (26 worktrees, 178p/1f). OpenAI (45 worktrees, 209p/1f). DeepSeek (68 worktrees, 298p/168f). DeepSeek's failures are architectural choices (FastAPI instead of Flask, missing async deps) — not logic errors. AST analysis confirms GPT writes fewer, larger files with higher function density than DeepSeek.

Output-Based Semantic Validation — No Embeddings

Three orthogonal output-based methods: (1) pragmatic marker analysis — counting explanatory/surface/constraint keywords in reasoning text; (2) AST edit distance — comparing code structure; (3) tool-call latency — measuring exploration before writing. All methods work on any model's text output. No model internals required. No incompatible vector spaces. 205 sessions analyzed. Constraint markers spike 10× under perturbation — correct perturbation classification confirmed.

Research Context:
Liu et al. (2026, arXiv:2605.11733) — "LLM Inference Should Be Evaluated as Energy-to-Token Production." Our instrument implements their framework: measuring agentic build cost in dollar and token terms.

TokenPowerBench (Niu et al., AAAI 2026) — Empirical J/token measurements (0.1–2 J/tok). We use the conservative lower bound (0.1 J/tok). MoE architectures show 5–20× lower J/token than dense models.

Zhu & Zhu (2026, arXiv:2603.28949) — "The Planetary Cost of AI Acceleration." Claude's per-token pricing (455–2,273× DeepSeek) dwarfs any plausible hardware efficiency difference. The bottleneck is economic, not physical.

CARL (ACL 2026) — Constraint-Aware RL framework. Our instrument extends from training-time to inference-time measurement: what does it cost to recover a missing constraint at deployment?

TRACED (2026) — Geometric kinematics of reasoning traces. Our tool-call latency method provides a behavioral proxy without requiring model internals.

Honest Constraints

Reasoning-time constraint detection requires logit lens or activation patching — unattainable via API. We measure through code-file scanning, pragmatic marker analysis, and AST comparison. Cross-model embedding analysis is replaced by output-based semantic validation because provider embedding spaces are incompatible. These are acknowledged limitations, not hidden gaps.
