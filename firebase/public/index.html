How the framework works

1. Measure

Every model defaults to being a chatbot. When you give it degraded instructions — wrong specs, missing requirements — some maintain integrity. Most don't. Grit measures which ones recover and what recovery costs.

2. Route

Apply the 10 rules. Route routine work to high-Grit, low-cost models. Escalate only when reasoning is worth paying for. Cache intelligently — measure hit rates before choosing write vs read strategy.

3. Compound

Persistent organizational memory. Every project, every deployment, every incident feeds into a system where the model never rebuilds context it's already learned. Intelligence compounds instead of being billed repeatedly.
