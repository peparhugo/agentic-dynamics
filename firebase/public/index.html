Physics

Why 1 token ≠ 1 token.

DeepSeek activates 37B of 671B parameters per token (MoE, 5.5%). Claude is dense — all parameters fire on every forward pass. The energy cost of a token depends on how many transistors switch to produce it.

Physicist's Bounded Estimate

We don't guess a single energy number. We compute a bounded range from observables (tokens), disclosed architecture (active params), and known hardware (GPU TDP).

How It Works

The measurement pipeline.

Each experiment spawns an isolated opencode session in a fresh git worktree. The model builds real code, writes real tests, and runs them. We capture every tool call, token, and dollar.

6Strategy classified: conservative / exploratory / wasteful / efficientStrategy type, thermal efficiency

Game Theory

Multifactorial experiment design.

Each session is a round. Each perturbation is an intervention. We isolate six factors and measure four interactions.

6 Factors Isolated

Model architecture (MoE vs dense), perturbation class (manifold vs semantic), perturbation strength (0.3/0.5/0.8), phase count (1/4/8), codebase size (5/50/500 files), task type (build/refactor/extend/redesign)

4 Interactions Measured

Model × Phase (does Claude's advantage invert?), Perturbation × Phase (compounding or recovery?), Codebase × Model (cache-write tax at scale?), Perturbation × Strength (threshold effects?)

Recovery Cost: The Phase 1→2 Bridge

Recovery Cost = Perturbed Cost − Baseline Cost. Answers: "removing constraint X costs $Y extra to re-derive."

Honest Accounting

What this data cannot support.

Critical gaps

All operator×strength cells are n=1. No confidence intervals. "Correctness" is a heuristic keyword check, not verified test pass/fail. All tasks are Python/Flask — no TypeScript, Rust, or data analysis domains tested. Manifold vs semantic classification is a hypothesis, not validated by embedding analysis.

What holds up

The dashboard-verified pricing gap ($0.022 vs $10–50/Mtok, 455–2,273x) is directly observed from provider dashboards. The perturbation response asymmetry (Claude drops 34pp, DeepSeek gains 3pp) is consistent across two task types — directional despite small samples. The instrument methodology (isolated worktrees, cumulative session accounting, opencode agentic harness) is reproducible and well-designed.
