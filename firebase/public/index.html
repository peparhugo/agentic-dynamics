The Research Question

AI inference is a thermodynamic process. Every token is heat. The question isn't which model is smarter — it's which model delivers correct work at lower thermal cost.

H₁ — The Alternative Hypothesis

RL-trained reasoning policies compress reasoning into latent-space navigation during training. Imitation-trained policies expand it into explicit token search. The instrument measures whether this produces more correct solutions per dollar — and whether the pricing model itself penalizes iterative agentic work.

H₀ — The Null Hypothesis

Training regime has no effect on thermodynamic efficiency. All models produce equivalent useful work per unit of energy consumed. Cost differences are purely pricing artifacts.

Why the Gap Exists

Three mechanisms, all verified from experiment data.

📦 Cache-write tax: Claude charges $10/M input tokens for the full context window every session — whether the token is new or cached. A 30K-token codebase costs $0.30 just to load, before any work begins. Across our 17 Claude sessions, cache writes (332K tokens) accounted for 75% of paid tokens but 0% of productive output. DeepSeek doesn't separately bill for cached context.
💸 Pricing model, not energy: Claude charges $10–50/Mtok. DeepSeek charges $0.022/Mtok (dashboard-verified: 337M tokens for $7.38). The 455–2,273x per-token price gap dwarfs any plausible hardware efficiency difference. This is a business model difference, not a physics one.
🧠 Perturbation survival: When given perturbed prompts (alien vocabulary, missing constraints, inverted framing), Claude stopped building entirely on 40% of runs — producing 0 tool calls. DeepSeek built working code on 92% of runs regardless. Claude spent $0.14–1.26 per abandoned session producing nothing. The RL-trained policy pushes through confusion; the imitation-trained policy defaults to explanation.
