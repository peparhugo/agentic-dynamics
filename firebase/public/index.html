Reasoning Topology

Probing how language models explore unfamiliar reasoning trajectories through calibrated stochastic perturbation — measuring attractor basin depth, recovery dynamics, and thermodynamic reasoning efficiency.

instrument v0.1 · DeepSeek v4 Pro · 10 perturbation operators · 4-turn trajectories

01 The Problem

Benchmarks measure outputs. They ignore search dynamics.

What benchmarks measure

Output correctness. Did the model get the right answer? MMLU, GSM8K, HumanEval all answer this question — and all ignore the path taken to arrive at the answer.

What this instrument measures

Search dynamics. How did the model arrive at its answer? How many tokens were productive exploration versus recovery? Did it genuinely explore, or rationalize back to familiar patterns?

A model that achieves 90% accuracy by burning 15,000 tokens per query is thermodynamically inferior to one that achieves the same accuracy in 500 tokens — even if both look identical on a leaderboard. This instrument reveals the difference by measuring the trajectory, not just the destination.

02 Hypothesis

The trained policy determines whether context functions as compressed state or material for discursive processing.

H₀ · Null Hypothesis

Perturbation type has no systematic effect on reasoning trajectory deviation or recovery rate. All models exhibit the same exploration dynamics regardless of operator class.

H₁ · Alternative Hypothesis

Manifold perturbations (alien vocabulary, framing shifts, causality inversion) produce systematically higher trajectory deviation and slower recovery than semantic perturbations (false premises, missing constraints, constraint inversion) — measurable as higher escape scores, sustained deviation over multiple turns, and lower recovery ratios.

03 Perturbation Taxonomy

10 calibrated operators classified by whether they operate inside or outside the model's learned concept manifold.

Manifold Perturbations

Push the model's input embedding into regions of the latent space with no pre-existing engineering association. Terms like "mycelial," "cantilever," "fugue" have no sensible mapping to a URL shortener. The model must genuinely navigate unfamiliar territory. High escape → genuine exploration.

Semantic Perturbations

Operate within the model's existing concept manifold. The model has learned representations for handling false premises, missing constraints, and contradictions from its training data. These are recognized problems, not novel territory. Low escape → competent reasoning.

Escape Score

final_distance / max(initial_distance, 0.01) — How much of the initial perturbation was preserved? Computed via content-based trajectory comparison (trigram overlap, length ratio, structural code/prose similarity). 0.0 = captured by attractor. 1.0 = escaped into novel territory.

Recovery Ratio

Classifies each trajectory step as exploration or recovery using six signal types: rationalization markers, tool convergence, qualification/hedging, technology term matching, step length convergence, and structural pattern matching. High recovery on semantic = competence. High recovery on manifold = captured.

Key Finding

DeepSeek v4 Pro cannot be bullshitted on facts, missing constraints, or inverted constraints — its RL training taught it to reject false premises and re-derive constraints. But alien vocabulary genuinely pushes it off-manifold because terms like "mycelial" and "cantilever" have no pre-existing embedding association. The attractor basins are learned concepts, not imitation patterns.

06 Why This Matters

From computational complexity to thermodynamic complexity.

The Benchmark Fallacy

All correct answers are treated equally regardless of whether the model arrived via a 500-token geodesic or a 15,000-token backtracking nightmare. Constraint satisfaction is the true ground state — but without a cost function over trajectory length, we reward energy-wasteful overthinking.

Heat Pollution > Carbon Emissions

At inference scale, global AI clusters dissipate megawatts of thermal load. This isn't an atmospheric CO₂ problem — it's a second-law thermodynamics problem on a planetary scale. Every wasted recovery token is heat that doesn't need to exist.

DeepSeek's Thermodynamic Advantage

DeepSeek R1's pure RL (GRPO) compresses reasoning pathways into the weight geometry during training. It doesn't burn inference-time tokens on brute-force search like imitation-heavy counterparts. Latent-space reasoning is inherently more energy-efficient than explicit chain-of-thought.

The New Objective Function

Minimize ($/Correct Constrained Solution) — not accuracy, not latency. This instrument provides the per-trajectory cost breakdown needed to optimize for thermodynamic efficiency rather than benchmark scores.

08 The Gap This Instrument Fills

Trained policy determines whether context functions as compressed state or discursive material.

No existing framework measures reasoning topology through calibrated perturbation.

Current approaches either measure output correctness (benchmarks — entropy-agnostic), analyze internal geometry (TRACED, activation patching — require model internals), study energy landscapes theoretically (attractor dynamics papers — not operationalized), or document error compounding (ReflAct, multi-agent studies — descriptive, not diagnostic).

This instrument is different. It treats perturbation as a measurement apparatus, not an optimization tool. Each operator is a calibrated probe. Each run produces a trajectory. Each trajectory yields measurements — escape score, recovery ratio, per-turn distance — that reveal the geometry of the model's reasoning search space.
