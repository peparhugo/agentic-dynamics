Numbers are tagged by provenance: [M] measured from API/session data · [C] computed from measurements · [H] heuristic estimate · [X] externally sourced. ▶ TL;DR — What the evidence proves

Across 248 experiment sessions spanning 8 model variants and 3 architectures, we measured a 65× cost gap between DeepSeek v4 Pro ($0.015/session) and Claude Fable 5 ($1.01/session) — for identical constraint-complete code. The gap widens to 200× on TypeScript. The cause isn't capability; both models implement all 7 constraints. It's architecture: DeepSeek's GRPO compresses reasoning into latent space; Claude's SFT chain-of-thought bills every reasoning step as output tokens. The tables below present the full data — AST analysis, token economics, perturbation response, and constraint verification.

Manifold Operators (4)
Push the model off its typical linguistic surface — alien vocabulary injection, framing shifts, causality reversal, forced abandonment. Test search dynamics.
Semantic Operators (6)
Inject contradictions within the reasoning manifold — false premises, inverted constraints, phantom successes, competing goals, removed critical constraints, contradiction insertion. Test truth-seeking policies.
Detector: Recovery Signals (6)
Markers, tool convergence, qualifier patterns, tech stack convergence, output length ratio, reasoning structure overlap. Classify every segment as EXPLORATION or RECOVERY.
Detector: Strategy Archetypes (4)
CONSERVATIVE (low explore, high recover), EXPLORATORY (high escape, low recover), WASTEFUL (high explore, low quality), EFFICIENT (high explore, high quality, low cost).

Current Scope & What's Next

This is v0.3 – the first open framework for AI FinOps. Here's what's validated today and what's on the roadmap.

Covered Today
Python/Flask REST APIs, SQLite-backed CRUD apps, JWT auth flows, rate-limited endpoints, paginated responses, audit-logged systems, API versioning, pytest suites, real-time collaboration frontends. TypeScript/Node.js (initial: 3 variants, 21 cross-model runs). 10 prompt-level perturbation operators (4 manifold, 6 semantic). IEA-baseline EPM projection (1.6%/yr). Cost measurement: tokens, dollars, joules.
Planned (v0.3+)
Rust, Go validation. Structural perturbation operators (broken dependencies, AST corruption, production incident simulation). EPM sensitivity analysis (aggressive/optimistic/volatile scenarios). Human maintenance cost modeling. Pull requests welcome – the framework was designed for extensibility from day one.
Not in Scope
The framework does not judge whether narration is wasteful or valuable. It measures the cost. If your team needs auditable reasoning trails for compliance or debugging, the Explanation Tax is insurance – not overhead. The instrument is model-agnostic. DeepSeek was chosen as the anchor case study, not an endorsement.
Test Pass Rate Caveat
Sampled pytest results are environment-sensitive. Approximately 31% of failures resolve with correct dependency installation. The raw pass rate counts everything; the "with correct env" column estimates real code quality. DeepSeek's 69% corrected rate is comparable to Claude and GPT-5.6.
Energy Projection Caveat
The EPM uses a linear IEA-based projection. Real-world energy prices may diverge significantly. v0.3 will add sensitivity analysis with aggressive (2.5%/yr), baseline (1.6%/yr), and optimistic (0.8%/yr) scenarios.
