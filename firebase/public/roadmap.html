Pillar 4: Structural Perturbations CTO

Our current operators are semantic (changing the prompt). We need to break the system, not just the words.

Pillar 5: The Maintenance Tax CFO CEO

The most expensive part of AI-generated code is human debugging time. We need to measure this.

StudyStatusMethod
6-Month Code EvolutionPlannedGenerate code from Silent vs. Explanatory models. Give both to human developers. Track time-to-fix, cyclomatic complexity, and bug recurrence over 6 simulated sprints.
Blind Preference TestHelp WantedGive developers both outputs without source labels. Which do they prefer to maintain and why?

How to Contribute

Items marked Help Wanted are actively seeking external runs. The instrument is open source and designed for extensibility.

  1. Fork the repo: github.com/peparhugo/ai-finops-rulebook
  2. Configure: Create or modify a config in experiments/configs/ for your chosen stack, task, or model
  3. Run: python scripts/run.py --config experiments/configs/your-config.yaml
  4. Submit: Open a PR with your results JSON and any generated worktree output
  5. We verify: We validate the methodology and merge your findings, crediting you on this page

If you have API credits to contribute or want to coordinate on a specific pillar, reach out via GitHub Issues. We’re exploring grant funding to sponsor community experiments at scale.
