Autonomous Workloads

When AI works without human supervision — the rules, economics, and operational model

How Grit Controls Autonomous Workloads

The Grit framework directly governs unsupervised AI operations. In autonomous mode, you can't review every output. You need models that self-correct when given bad context — because bad context is inevitable in real systems (stale documentation, conflicting requirements, incomplete specifications).

  • Flail Rate determines which models should NEVER be in autonomous cascades. GPT-5-nano (100% flail) and GPT-5-mini (58% flail) cannot be trusted unsupervised.
  • Recovery Cost compounds across thousands of autonomous sessions. Claude writes 22,500 tokens to cache per session at $15/Mtok. At 5,000 jobs/day, that's $1,688/day in cache overhead alone. Switch to cache-read for autonomous batch processing.
  • First-Pass Success (Rule 5) IS Grit in production. Track WOC by model, task type, and time of day.

Real-World Autonomous Patterns

Autonomous AI maps directly to established workforce management disciplines:

  • Call Center / Task Queue: AHT (average handle time) = steps per session. Service level = % of tasks resolved within SLA buffer (Rule 9).
  • Back-Office Processing: Batch window = 72-hour horizon (Rule 6). Throughput cap = budget / cost-per-job (Rule 7).
  • CI/CD Pipelines: Cascade routing = escalation chain (Rule 8). Grit determines which models auto-resolve vs escalate to human review.
  • Agentic Workflows: Multi-step autonomous tasks require high-Grit models that can recover from intermediate failures without flailing.

WOC Ratio — Rule 5 (First-Pass)

The Work Overhead Cost ratio tells you whether autonomy is actually saving money.

WOC = (costvalidation + costretries + costescalations) / costprimary

Healthy

WOC < 0.70

Overhead is manageable. Scaling is safe.

Investigate

WOC < 0.85

Retry or escalation rate rising. Tune thresholds.

Critical

WOC ≥ 0.85

Overhead dominates. Pause autonomy until root cause found.

Calculated: WOC = 0.90 from retry rate r=0.115 across 248 experiment sessions.
